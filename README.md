# Baloncesto-3x3-inclusivo
Esta Situación de Aprendizaje acerca al alumnado al baloncesto 3x3 desde una perspectiva inclusiva, inspirada en el baloncesto en silla de ruedas. Mediante experiencias prácticas, vivencian adaptaciones del deporte, desarrollando empatía, respeto y conciencia sobre la igualdad de oportunidades.
